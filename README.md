# Cloud-Based Energy Consumption Forecasting and Optimization System Using Machine Learning

## Project Overview
This project analyzes historical electricity consumption data, trains a machine learning model, forecasts electricity demand for the next 24 hours, and provides rule-based energy optimization recommendations.

## Features
- Upload electricity consumption data in CSV format
- Analyze historical energy consumption
- Visualize energy demand using graphs
- Train and evaluate a Random Forest regression model
- Evaluate performance using MAE, RMSE, and MAPE
- Forecast electricity demand for the next 24 hours
- Generate rule-based recommendations based on forecast demand

## Technologies Used
- Python
- Streamlit
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

## Current Status
The application runs locally using Streamlit. Cloud deployment and multi-cloud redundancy are planned future improvements.

## How to Run
1. Install the required dependencies.
2. Run `streamlit run app.py` in the project directory.
3. Upload a compatible electricity consumption CSV file or select the demo dataset.
